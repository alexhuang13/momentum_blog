动量 · 稳定性 · Scaling laws

大 batch 训练中的动量

Polyak 扩大临界 batch size，
Nesterov 提高数据效率

我们以幂律核回归为可分析的模型，研究在 one-pass 训练中，动量何时以及如何改善大 batch 训练。我们首先刻画风险稳定性，然后推导完整风险动力学的缩放规律，最后在固定数据预算下优化最终迭代的风险。

01

引言

动量是现代大规模训练中优化器设计的核心机制之一，Adam 和 Muon 等常用优化器都包含动量。经典理论主要将动量视为加速机制，并通过迭代复杂度的降低来衡量其作用。然而，仅靠迭代复杂度还不足以完整描述动量在现代大规模训练中的作用：随着数据和硬件内存等训练资源的增长，优化所处的训练区间本身也会发生变化。

现代大规模训练，特别是语言模型预训练，通常采用 one-pass 训练。在这一设定下，batch size BBB 不仅控制硬件并行度，也决定优化的时间范围：给定数据预算 DDD，顺序更新次数为

T=DB.T=\frac{D}{B}.T=BD​.

更大的 batch 可以提高硬件利用率和训练吞吐量，但也必然减少每轮数据遍历中可用的优化步数。这构成了硬件效率与数据效率之间的基本权衡。因此，我们关注以下问题：

动量能否在不损失数据效率的情况下支持更大的 batch，甚至进一步提高数据效率本身？

我们以幂律核回归（power-law kernel regression，PLK）为可分析的学习问题，研究 Polyak 和 Nesterov 这两种经典动量方法。其无限维幂律谱覆盖了广泛的学习时间尺度，使得动量在不同谱方向上的作用可以被明确分析。问题由两个指数刻画：容量指数 β>1\beta>1β>1 控制特征谱的衰减，源指数 s>0s>0s>0 控制目标函数能量在谱上的分布。

我们的分析首先通过稳定性确定允许的超参数区域，然后推导描述风险动力学的缩放规律，最后在稳定性约束与 one-pass 约束 T=D/BT=D/BT=D/B 下优化最终迭代的风险。

sss 越小，越多目标能量分布在低曲率、小特征值方向，学习问题也就越难。数据缩放分析考虑常数量级的标签噪声。Batch size、学习率和动量系数可以随数据预算变化，但在每次训练过程中保持固定。

动量为何改善大 batch 训练

动量收益对 batch size 的依赖，可以通过每样本有效学习率来理解：

ηsample:=ηeffB,ηeff={η,SGD,ηρ:=η/(1−ρ),momentum.\eta_{\mathrm{sample}}:=\frac{\eta_{\mathrm{eff}}}{B},\qquad \eta_{\mathrm{eff}}=\begin{cases}\eta,&\text{SGD},\\[2pt]\eta_\rho:=\eta/(1-\rho),&\text{momentum}.\end{cases}ηsample​:=Bηeff​​,ηeff​={η,ηρ​:=η/(1−ρ),​SGD,momentum.​

Polyak：允许的有效学习率范围

忽略早期瞬态并代入 T=D/BT=D/BT=D/B，SGD 和 Polyak 满足相同的数据层面信号—噪声权衡：

E(D)≍(Dηsample)−s+σ2ηsample.\mathcal E(D)\asymp(D\eta_{\mathrm{sample}})^{-s}+\sigma^2\eta_{\mathrm{sample}}.E(D)≍(Dηsample​)−s+σ2ηsample​.

两者的差别在于每样本有效学习率的允许范围。稳定性条件对 SGD 给出 ηsample≲1/B\eta_{\mathrm{sample}}\lesssim1/Bηsample​≲1/B，而 Polyak 允许 ηsample≲1\eta_{\mathrm{sample}}\lesssim1ηsample​≲1。因此，随着 batch size 增大，SGD 允许的每样本有效学习率按 1/B1/B1/B 缩小；Polyak 则可以通过让 ηρ\eta_\rhoηρ​ 随 BBB 成比例增长，将其保持在常数量级。

Polyak 因而将 SGD 的信号—噪声权衡延伸到了显著更大的 batch size，而不改变这一权衡的最优值。这同时解释了临界 batch size 的扩大，以及最优数据缩放指数保持不变的原因。

Nesterov：噪声累积的抑制

Nesterov 与 Polyak 的差别来自 look-ahead 机制诱导的曲率自适应阻尼，它对更陡峭的方向施加更强的阻尼。这一机制保留了渐近幂律信号项 (kηρ)−s(k\eta_\rho)^{-s}(kηρ​)−s，同时抑制了随机噪声累积。当 ηρ≫1\eta_\rho\gg1ηρ​≫1 时，Polyak 的噪声平台按 σ2ηρ/B\sigma^2\eta_\rho/Bσ2ηρ​/B 缩放，而 Nesterov 按 σ2ηρ1/β/B\sigma^2\eta_\rho^{1/\beta}/Bσ2ηρ1/β​/B 缩放。

这改善了信号—噪声权衡本身，使 Nesterov 在大 batch 区间达到更好的数据效率。然而，当 batch size 进一步增大时，有限的顺序更新次数 T=D/BT=D/BT=D/B 成为主导瓶颈，两种动量方法重新具有相同的信号受限缩放。

07

结论与讨论

我们对大 batch、one-pass 训练中的 Polyak 和 Nesterov 动量进行了统一分析，刻画了风险稳定性、风险动力学以及最优数据缩放。一个核心结论是，动量的收益显著依赖于 batch size。在小 batch 区间，两种方法都不改善普通 SGD 的数据缩放指数。随着 batch size 增大，Polyak 在比 SGD 显著更宽的 batch-size 范围内保持小 batch 的最优数据缩放指数，而 Nesterov 在大 batch 区间进一步改善数据缩放指数。在超大 batch 区间，训练受到顺序更新次数的限制，两种动量方法重新呈现相同的信号受限缩放。

这些结果表明，学习率、batch size 和动量应当被联合设计。稳定性条件决定了在给定学习率和 batch size 下，动量能够增加到什么程度；缩放规律则量化了更快的信号学习与更强的噪声累积之间的权衡。将这一框架推广到随时间变化的学习率、batch size 和动量系数，有望为大规模训练中这些超参数的联合缩放与调度提供理论指导。
