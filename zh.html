介绍动量时，我们通常会说它能加快梯度下降。但如果每条训练数据只用一次，还有一个值得问的问题：用了动量之后，batch size 能开到多大？

数据量固定时，batch 越大，参数更新的次数越少。这篇文章用一个简单的回归模型，逐步比较 SGD、Polyak 和 Nesterov 在这件事上的差别。主要结果是：Polyak 让我们把 batch 开得更大，仍然保持原来的数据效率；Nesterov 则有机会进一步提高数据效率。要理解这个区别，需要把学习速度和噪声放在一起看。

Batch size 和数据预算

假设我们有 DDD 条训练数据，每条只用一次。每个 batch 放 BBB 条数据，那么更新次数就是

T=DB.T=\frac{D}{B}.T=BD​.

比如，100 万条数据，batch size 为 100 时可以更新 1 万步，batch size 为 1,000 时就只剩 1,000 步。数据量没变，模型调整参数的机会却少了很多。

大 batch 可以更好地利用并行硬件，但能不能用好这些数据，还要看优化器在剩下的步数里能学到多少。下文中，每次训练的 batch size、学习率和动量都保持固定；当数据预算改变时，我们可以重新选择这些设置。

一个有快有慢的学习问题

我们用幂律核回归来研究这个问题。模型的预测是 f(x;θ)=⟨ϕ(x),θ⟩f(x;\theta)=\langle\phi(x),\theta\ranglef(x;θ)=⟨ϕ(x),θ⟩，标签则是目标预测加上噪声：

y=⟨ϕ(x),θ∗⟩+ϵ,ϵ∼N(0,σ2).y=\langle\phi(x),\theta^*\rangle+\epsilon,\qquad \epsilon\sim\mathcal N(0,\sigma^2).y=⟨ϕ(x),θ∗⟩+ϵ,ϵ∼N(0,σ2).

特征服从高斯分布，协方差记作 HHH。沿着它的特征向量来看，特征值 λj\lambda_jλj​ 表示第 jjj 个方向的曲率。特征值大的方向通常学得快，特征值小的方向要花更长时间。这里假设特征谱和目标满足

λj≍j−β,λj∣θj∗∣2≍j−(1+sβ).\lambda_j\asymp j^{-\beta},\qquad \lambda_j|\theta_j^*|^2\asymp j^{-(1+s\beta)}.λj​≍j−β,λj​∣θj∗​∣2≍j−(1+sβ).

β>1\beta>1β>1 控制特征值衰减得多快，s>0s>0s>0 描述有多少要学的内容落在慢方向上。sss 越小，学习问题越难。符号 ≍\asymp≍ 表示两边可以相差常数倍，但缩放关系相同。

我们衡量的是超额预测风险，也就是从平方误差中去掉无法消除的标签噪声：

E(θ)=12∑jλj(θj−θj∗)2.\mathcal E(\theta)=\frac12\sum_j\lambda_j(\theta_j-\theta_j^*)^2.E(θ)=21​j∑​λj​(θj​−θj∗​)2.

下文把它简称为“误差”，用 E(k)\mathcal E(k)E(k) 表示更新 kkk 步后的期望误差。讨论数据缩放时，σ2\sigma^2σ2 随数据量增长保持常数量级。

Polyak 和 Nesterov 动量

用 gk(θ)g_k(\theta)gk​(θ) 表示第 kkk 步新取的一个 batch 上的平均梯度。普通 SGD 的更新是

θk+1=θk−ηgk(θk),\theta_{k+1}=\theta_k-\eta g_k(\theta_k),θk+1​=θk​−ηgk​(θk​),

其中 η\etaη 是学习率。动量会把上一步更新的信息加进来。为了方便，把上一步的位移写成 vk=θk−θk−1v_k=\theta_k-\theta_{k-1}vk​=θk​−θk−1​。

Polyak：把上一步的位移带过来

Polyak 动量也叫 heavy-ball 方法。它先更新位移，再更新参数：

vk+1=ρvk−ηgk(θk),θk+1=θk+vk+1.\begin{aligned}v_{k+1}&=\rho v_k-\eta g_k(\theta_k),\\\theta_{k+1}&=\theta_k+v_{k+1}.\end{aligned}vk+1​θk+1​​=ρvk​−ηgk​(θk​),=θk​+vk+1​.​

ρ∈[0,1)\rho\in[0,1)ρ∈[0,1) 控制保留多少之前的位移。如果连续几步的梯度方向比较一致，这些贡献就会累积起来。

Nesterov：往前看一点，再算梯度

Nesterov 用同样的位移先构造一个 look-ahead 点，然后在那个位置计算梯度：

θkla=θk+ρvk,vk+1=ρvk−ηgk(θkla),θk+1=θk+vk+1.\begin{aligned}\theta_k^{\mathrm{la}}&=\theta_k+\rho v_k,\\v_{k+1}&=\rho v_k-\eta g_k(\theta_k^{\mathrm{la}}),\\\theta_{k+1}&=\theta_k+v_{k+1}.\end{aligned}θkla​vk+1​θk+1​​=θk​+ρvk​,=ρvk​−ηgk​(θkla​),=θk​+vk+1​.​

表面上看，只是计算梯度的位置变了。但在二次问题里，同样的位移会让高曲率方向的梯度变化更多。因此，look-ahead 会改变各个方向受到的阻尼。后面讨论噪声时，这一点会变得很关键。

有效学习率从哪里来？

想直观地理解动量更新有多大，可以先假设梯度 ggg 近似不变，并从 v0=0v_0=0v0​=0 开始。把 Polyak 的更新展开：

vk+1=−η∑i=0kρig=−η1−ρk+11−ρg.v_{k+1}=-\eta\sum_{i=0}^{k}\rho^i g=-\eta\frac{1-\rho^{k+1}}{1-\rho}g.vk+1​=−ηi=0∑k​ρig=−η1−ρ1−ρk+1​g.

等最初的影响消退后，梯度前面的系数近似是 η/(1−ρ)\eta/(1-\rho)η/(1−ρ)。这就是有效学习率的直觉来源：

ηρ:=η1−ρ.\eta_\rho:=\frac{\eta}{1-\rho}.ηρ​:=1−ρη​.

梯度不变只是一个帮助理解的例子，实际的随机训练还需要进一步分析。不过，两种动量方法在慢方向上的长期学习，确实都由这个量控制。比如，ρ=0.9\rho=0.9ρ=0.9 时，ηρ=10η\eta_\rho=10\etaηρ​=10η；ρ=0.99\rho=0.99ρ=0.99 时，就变成了 100η100\eta100η。

提高 ρ\rhoρ 可以增大有效学习率。但在用它加速之前，得先确认误差不会发散。在大 batch、高动量的设定下，最大的稳定学习率有下面的缩放关系：

学习速度和噪声平台

早期过渡阶段结束后，误差主要有两个来源。一部分是模型还没学会的信号，会随着更新次数增加而减小；另一部分来自随机噪声，会留下一个光靠多走几步无法消除的平台。

对于 SGD，缩放关系是

ESGD(k)≍(kη)−s⏟signal still to learn+σ2ηB⏟noise floor.\mathcal E_{\mathrm{SGD}}(k)\asymp\underbrace{(k\eta)^{-s}}_{\text{signal still to learn}}+\underbrace{\frac{\sigma^2\eta}{B}}_{\text{noise floor}}.ESGD​(k)≍signal still to learn(kη)−s​​+noise floorBσ2η​​​.

第一项是还没学会的信号，第二项是噪声平台。η\etaη 越大，第一项越小，第二项却越大。增大 batch 可以减少每步的噪声，但在固定数据预算下，也会减少总步数。

Polyak 保留了同一个权衡

对于 Polyak，把 η\etaη 换成有效学习率 ηρ\eta_\rhoηρ​：

EPolyak(k)≍(kηρ)−s+σ2ηρB.\mathcal E_{\mathrm{Polyak}}(k)\asymp(k\eta_\rho)^{-s}+\frac{\sigma^2\eta_\rho}{B}.EPolyak​(k)≍(kηρ​)−s+Bσ2ηρ​​.

动量加快了学习，也同时抬高了噪声平台。信号和噪声之间的权衡形式没有变，变化的是训练稳定时能用到多大的有效学习率。

Nesterov 降低了噪声代价

Nesterov 的主要学习项一样，但噪声平台不同：

ENesterov(k)≍(kηρ)−s+σ2Bmin⁡{ηρ,ηρ1/β}.\mathcal E_{\mathrm{Nesterov}}(k)\asymp(k\eta_\rho)^{-s}+\frac{\sigma^2}{B}\min\{\eta_\rho,\eta_\rho^{1/\beta}\}.ENesterov​(k)≍(kηρ​)−s+Bσ2​min{ηρ​,ηρ1/β​}.

当 ηρ≲1\eta_\rho\lesssim1ηρ​≲1 时，它看起来和 Polyak 一样。当 ηρ≫1\eta_\rho\gg1ηρ​≫1 时，噪声按 ηρ1/β\eta_\rho^{1/\beta}ηρ1/β​ 增长，比 ηρ\eta_\rhoηρ​ 更慢。在这个模型里，look-ahead 对更陡的方向施加更强的阻尼，减少这些方向上的噪声累积，同时保留幂律学习项。

因此，Nesterov 可以增大有效学习率，而不用付出同样大的噪声代价。这正是改善数据效率所需要的那一步。

从训练步数算到数据效率

现在可以回到固定数据预算的问题了。把 T=D/BT=D/BT=D/B 代入误差公式，并定义每条样本对应的有效学习率：

a:=ηeffB,ηeff={η,SGD,ηρ,momentum.a:=\frac{\eta_{\mathrm{eff}}}{B},\qquad\eta_{\mathrm{eff}}=\begin{cases}\eta,&\text{SGD},\\\eta_\rho,&\text{momentum}.\end{cases}a:=Bηeff​​,ηeff​={η,ηρ​,​SGD,momentum.​

比如，batch size 和有效学习率同时翻倍，aaa 就保持不变。用这个量，可以更方便地比较同样的数据被分成不同步数来训练时的表现。

为什么 Polyak 能支持更大的 batch？

等早期过渡的影响可以忽略后，SGD 和 Polyak 都满足

E(D)≍(Da)−s+σ2a.\mathcal E(D)\asymp(Da)^{-s}+\sigma^2a.E(D)≍(Da)−s+σ2a.

噪声是常数量级，因此最好的选择会让两项达到平衡。先忽略常数因子：

(Da)−s≍aas+1≍D−sa∗≍D−s/(s+1),E∗≍D−s/(s+1).\begin{aligned}(Da)^{-s}&\asymp a\\a^{s+1}&\asymp D^{-s}\\a_*&\asymp D^{-s/(s+1)},\qquad\mathcal E_*\asymp D^{-s/(s+1)}.\end{aligned}(Da)−sas+1a∗​​≍a≍D−s≍D−s/(s+1),E∗​≍D−s/(s+1).​

对 SGD 来说，稳定性要求 a≲1/Ba\lesssim1/Ba≲1/B。想选到这个平衡点，就需要 D−s/(s+1)≲1/BD^{-s/(s+1)}\lesssim1/BD−s/(s+1)≲1/B，也就是

B≲Ds/(s+1).B\lesssim D^{s/(s+1)}.B≲Ds/(s+1).

这就是 SGD 的临界 batch 规模。超过它，即使学习率已经开到稳定范围内的最大值，也够不到那个平衡点了。Polyak 的稳定性限制是 a≲1a\lesssim1a≲1，空间更大，因此在更大的 batch 下仍然可以达到同样的最优值。

为什么步数还是会成为限制？

还有一个条件需要考虑。高动量时，早期过渡大约需要 (1−ρ)−1(1-\rho)^{-1}(1−ρ)−1 步才能消退，另外还有对数修正。对于长度为 TTT 的训练，使用长期公式前需要满足 T(1−ρ)≳1T(1-\rho)\gtrsim1T(1−ρ)≳1。

为什么 Nesterov 能改善指数？

对 Nesterov，在 ηρ=Ba≫1\eta_\rho=Ba\gg1ηρ​=Ba≫1 时做同样的代换，得到

ENesterov(D)≍(Da)−s+σ2B1/β−1a1/β.\mathcal E_{\mathrm{Nesterov}}(D)\asymp(Da)^{-s}+\sigma^2B^{1/\beta-1}a^{1/\beta}.ENesterov​(D)≍(Da)−s+σ2B1/β−1a1/β.

训练曲线里能看到什么？

前面的指数描述数据量很大时的趋势。我们也在同一个回归模型里做了模拟，看看数据有限时，这些预测能不能对上。

同样的数据，换不同的 batch size

固定 D=214D=2^{14}D=214，每个 batch size 下都重新调学习率和动量，让最终误差尽量低。小 batch 时，SGD、Polyak 和 Nesterov 的误差几乎一样。Batch 逐渐增大，SGD 最先变差，Polyak 则能更久地保持之前的表现。

Nesterov 的误差会先下降，再转头上升。在下降的那段范围里，仅仅改变 batch size 并配合调参，就能让它从同样的数据里学到更多。

几个值得记住的点

Polyak 和 Nesterov 都通过有效学习率 η/(1−ρ)\eta/(1-\rho)η/(1−ρ) 加快学习。Polyak 保留了 SGD 在学习和噪声之间的最佳平衡，但可以在更大的 batch 下达到它。Nesterov 则在大有效学习率下降低噪声代价，连这个平衡点本身也改善了。

Batch size 决定了我们能不能用上这些收益。小 batch 时，三种方法的数据缩放指数一样；中间这段范围，动量有了发挥空间；batch 非常大时，两种动量方法最终都会受限于更新次数太少。

这里讨论的是 one-pass 核回归，每次训练中的超参数保持固定。这些结果给了我们一个理由，把学习率、batch size 和动量放在一起考虑。进一步允许它们随训练过程变化，是一个自然的下一步。
