动量如何帮助大 batch 训练？

{{BYLINE}} {{POST_META}}
{{CONTENTS}}

介绍动量时，我们通常会说它能加快梯度下降。但如果每条训练数据只用一次，还有一个值得问的问题：用了动量之后，batch size 能开到多大？

数据量固定时，batch 越大，参数更新的次数越少。这篇文章用一个简单的回归模型，逐步比较 SGD、Polyak 和 Nesterov 在这件事上的差别。主要结果是：Polyak 让我们把 batch 开得更大，仍然保持原来的数据效率；Nesterov 则有机会进一步提高数据效率。要理解这个区别，需要把学习速度和噪声放在一起看。

Batch size 和数据预算

假设我们有 \(D\) 条训练数据，每条只用一次。每个 batch 放 \(B\) 条数据，那么更新次数就是

\[T=\frac{D}{B}.\]

比如，100 万条数据，batch size 为 100 时可以更新 1 万步，batch size 为 1,000 时就只剩 1,000 步。数据量没变，模型调整参数的机会却少了很多。

大 batch 可以更好地利用并行硬件，但能不能用好这些数据，还要看优化器在剩下的步数里能学到多少。下文中，每次训练的 batch size、学习率和动量都保持固定；当数据预算改变时，我们可以重新选择这些设置。

一个有快有慢的学习问题

我们用幂律核回归来研究这个问题。模型的预测是 \(f(x;\theta)=\langle\phi(x),\theta\rangle\)，标签则是目标预测加上噪声：

\[y=\langle\phi(x),\theta^*\rangle+\epsilon,\qquad \epsilon\sim\mathcal N(0,\sigma^2).\]

特征服从高斯分布，协方差记作 \(H\)。沿着它的特征向量来看，特征值 \(\lambda_j\) 表示第 \(j\) 个方向的曲率。特征值大的方向通常学得快，特征值小的方向要花更长时间。这里假设特征谱和目标满足

\[\lambda_j\asymp j^{-\beta},\qquad \lambda_j|\theta_j^*|^2\asymp j^{-(1+s\beta)}.\]

\(\beta>1\) 控制特征值衰减得多快，\(s>0\) 描述有多少要学的内容落在慢方向上。\(s\) 越小，学习问题越难。符号 \(\asymp\) 表示两边可以相差常数倍，但缩放关系相同。

我们衡量的是超额预测风险，也就是从平方误差中去掉无法消除的标签噪声：

\[\mathcal E(\theta)=\frac12\sum_j\lambda_j(\theta_j-\theta_j^*)^2.\]

下文把它简称为“误差”，用 \(\mathcal E(k)\) 表示更新 \(k\) 步后的期望误差。讨论数据缩放时，\(\sigma^2\) 随数据量增长保持常数量级。

Polyak 和 Nesterov 动量

用 \(g_k(\theta)\) 表示第 \(k\) 步新取的一个 batch 上的平均梯度。普通 SGD 的更新是

\[\theta_{k+1}=\theta_k-\eta g_k(\theta_k),\]

其中 \(\eta\) 是学习率。动量会把上一步更新的信息加进来。为了方便，把上一步的位移写成 \(v_k=\theta_k-\theta_{k-1}\)。

Polyak：把上一步的位移带过来

Polyak 动量也叫 heavy-ball 方法。它先更新位移，再更新参数：

\[\begin{aligned}v_{k+1}&=\rho v_k-\eta g_k(\theta_k),\\\theta_{k+1}&=\theta_k+v_{k+1}.\end{aligned}\]

\(\rho\in[0,1)\) 控制保留多少之前的位移。如果连续几步的梯度方向比较一致，这些贡献就会累积起来。

Nesterov：往前看一点，再算梯度

Nesterov 用同样的位移先构造一个 look-ahead 点，然后在那个位置计算梯度：

\[\begin{aligned}\theta_k^{\mathrm{la}}&=\theta_k+\rho v_k,\\v_{k+1}&=\rho v_k-\eta g_k(\theta_k^{\mathrm{la}}),\\\theta_{k+1}&=\theta_k+v_{k+1}.\end{aligned}\]

表面上看，只是计算梯度的位置变了。但在二次问题里，同样的位移会让高曲率方向的梯度变化更多。因此，look-ahead 会改变各个方向受到的阻尼。后面讨论噪声时，这一点会变得很关键。

有效学习率从哪里来？

想直观地理解动量更新有多大，可以先假设梯度 \(g\) 近似不变，并从 \(v_0=0\) 开始。把 Polyak 的更新展开：

\[v_{k+1}=-\eta\sum_{i=0}^{k}\rho^i g=-\eta\frac{1-\rho^{k+1}}{1-\rho}g.\]

等最初的影响消退后，梯度前面的系数近似是 \(\eta/(1-\rho)\)。这就是有效学习率的直觉来源：

\[\eta_\rho:=\frac{\eta}{1-\rho}.\]

梯度不变只是一个帮助理解的例子，实际的随机训练还需要进一步分析。不过，两种动量方法在慢方向上的长期学习，确实都由这个量控制。比如，\(\rho=0.9\) 时，\(\eta_\rho=10\eta\)；\(\rho=0.99\) 时，就变成了 \(100\eta\)。

学习率要多大，训练才稳？

提高 \(\rho\) 可以增大有效学习率。但在用它加速之前，得先确认误差不会发散。在大 batch、高动量的设定下，最大的稳定学习率有下面的缩放关系：

方法最大的稳定学习率
SGD\(\eta_{\mathrm{SGD}}^{\mathrm{crit}}\asymp1\)
Polyak\(\eta_{\mathrm{Polyak}}^{\mathrm{crit}}\asymp\min\{1,B(1-\rho)\}\)
Nesterov\(\eta_{\mathrm{Nesterov}}^{\mathrm{crit}}\asymp\min\{1,B^\beta(1-\rho)\}\)

先看 Polyak 那一行。固定 \(\eta\)，让 \(\rho\) 越来越接近一，\(1-\rho\) 就越来越小，需要更大的 batch 来补偿。Nesterov 的补偿项是 \(B^\beta\)，因为 \(\beta>1\)，它能获得更多空间。

换成有效学习率来看，Polyak 允许 \(\eta_\rho\lesssim B\)，Nesterov 允许 \(\eta_\rho\lesssim B^\beta\)。这里省略了常数因子，学习率 \(\eta\) 本身也有一个常数量级的上限。这些关系解释了大 batch 为什么能支持更强的动量，但还没有告诉我们，哪个稳定设置学得最好。

学习速度和噪声平台

早期过渡阶段结束后，误差主要有两个来源。一部分是模型还没学会的信号，会随着更新次数增加而减小；另一部分来自随机噪声，会留下一个光靠多走几步无法消除的平台。

对于 SGD，缩放关系是

\[\mathcal E_{\mathrm{SGD}}(k)\asymp\underbrace{(k\eta)^{-s}}_{\text{signal still to learn}}+\underbrace{\frac{\sigma^2\eta}{B}}_{\text{noise floor}}.\]

第一项是还没学会的信号，第二项是噪声平台。\(\eta\) 越大，第一项越小，第二项却越大。增大 batch 可以减少每步的噪声，但在固定数据预算下，也会减少总步数。

Polyak 保留了同一个权衡

对于 Polyak，把 \(\eta\) 换成有效学习率 \(\eta_\rho\)：

\[\mathcal E_{\mathrm{Polyak}}(k)\asymp(k\eta_\rho)^{-s}+\frac{\sigma^2\eta_\rho}{B}.\]

动量加快了学习，也同时抬高了噪声平台。信号和噪声之间的权衡形式没有变，变化的是训练稳定时能用到多大的有效学习率。

Nesterov 降低了噪声代价

Nesterov 的主要学习项一样，但噪声平台不同：

\[\mathcal E_{\mathrm{Nesterov}}(k)\asymp(k\eta_\rho)^{-s}+\frac{\sigma^2}{B}\min\{\eta_\rho,\eta_\rho^{1/\beta}\}.\]

当 \(\eta_\rho\lesssim1\) 时，它看起来和 Polyak 一样。当 \(\eta_\rho\gg1\) 时，噪声按 \(\eta_\rho^{1/\beta}\) 增长，比 \(\eta_\rho\) 更慢。在这个模型里，look-ahead 对更陡的方向施加更强的阻尼，减少这些方向上的噪声累积，同时保留幂律学习项。

因此，Nesterov 可以增大有效学习率，而不用付出同样大的噪声代价。这正是改善数据效率所需要的那一步。

从训练步数算到数据效率

现在可以回到固定数据预算的问题了。把 \(T=D/B\) 代入误差公式，并定义每条样本对应的有效学习率：

\[a:=\frac{\eta_{\mathrm{eff}}}{B},\qquad\eta_{\mathrm{eff}}=\begin{cases}\eta,&\text{SGD},\\\eta_\rho,&\text{momentum}.\end{cases}\]

比如，batch size 和有效学习率同时翻倍，\(a\) 就保持不变。用这个量，可以更方便地比较同样的数据被分成不同步数来训练时的表现。

为什么 Polyak 能支持更大的 batch？

等早期过渡的影响可以忽略后，SGD 和 Polyak 都满足

\[\mathcal E(D)\asymp(Da)^{-s}+\sigma^2a.\]

噪声是常数量级，因此最好的选择会让两项达到平衡。先忽略常数因子：

\[\begin{aligned}(Da)^{-s}&\asymp a\\a^{s+1}&\asymp D^{-s}\\a_*&\asymp D^{-s/(s+1)},\qquad\mathcal E_*\asymp D^{-s/(s+1)}.\end{aligned}\]

对 SGD 来说，稳定性要求 \(a\lesssim1/B\)。想选到这个平衡点，就需要 \(D^{-s/(s+1)}\lesssim1/B\)，也就是

\[B\lesssim D^{s/(s+1)}.\]

这就是 SGD 的临界 batch 规模。超过它，即使学习率已经开到稳定范围内的最大值，也够不到那个平衡点了。Polyak 的稳定性限制是 \(a\lesssim1\)，空间更大，因此在更大的 batch 下仍然可以达到同样的最优值。

为什么步数还是会成为限制？

还有一个条件需要考虑。高动量时，早期过渡大约需要 \((1-\rho)^{-1}\) 步才能消退，另外还有对数修正。对于长度为 \(T\) 的训练，使用长期公式前需要满足 \(T(1-\rho)\gtrsim1\)。

结合 \(\eta\lesssim1\)，得到缩放意义下的上限：

\[\eta_\rho\lesssim T,\qquad a\lesssim\frac{T}{B}=\frac{D}{B^2}.\]

把这个上限和 \(a_*\asymp D^{-s/(s+1)}\) 放在一起。忽略对数因子，Polyak 能保持小 batch 指数的范围是

\[D^{-s/(s+1)}\lesssim\frac{D}{B^2}\quad\Longrightarrow\quad B\lesssim D^{(2s+1)/(2s+2)}.\]

超过这个规模，步数就不够了。学习项受到 \((T\eta_\rho)^{-s}\gtrsim T^{-2s}\) 的限制。如果 \(B\) 按 \(D^b\) 增长，就会得到后面出现的指数 \(2s(1-b)\)。这几步解释了幂次的来源，论文里会完整处理过渡阶段和对数因子。

为什么 Nesterov 能改善指数？

对 Nesterov，在 \(\eta_\rho=Ba\gg1\) 时做同样的代换，得到

\[\mathcal E_{\mathrm{Nesterov}}(D)\asymp(Da)^{-s}+\sigma^2B^{1/\beta-1}a^{1/\beta}.\]

换成每样本学习率之后，batch size 仍然留在噪声项里。因为 \(1/\beta-1<0\)，固定 \(a\) 时，更大的 batch 会让这一项变小。

把学习和噪声两项配平：

\[\begin{aligned}D^{-s}a^{-s}&\asymp B^{1/\beta-1}a^{1/\beta}\\a_*&\asymp D^{-s\beta/(s\beta+1)}B^{(\beta-1)/(s\beta+1)}.\end{aligned}\]

再代回误差公式，并写成 \(B\asymp D^b\)：

\[\mathcal E_{\mathrm{Nesterov}}(D)\asymp D^{-\frac{s(1+(\beta-1)b)}{s\beta+1}}.\]

这就是 Nesterov 数据缩放指数中间上升的那一段。它适用于大有效学习率下的平衡点仍然可行时。等步数再次成为主要限制，指数就会接到和 Polyak 一样的 \(2s(1-b)\) 上。

把不同 batch size 放在一起看

令 \(B=D^{b+o(1)}\)，其中 \(b\in[0,1)\)。在稳定范围内把超参数调到最优后，将最终误差写成 \(D^{-r(b)+o(1)}\)。\(r\) 越大，增加数据带来的改善越明显。小量 \(o(1)\) 允许存在不改变主导幂次的因子。

三个转折点分别是

\[b_1=\frac{s}{s+1},\qquad b_2=\frac{2s+1/\beta}{2s+1+1/\beta},\qquad b_3=\frac{2s+1}{2s+2}.\]

我们已经看到 \(b_1\) 和 \(b_3\) 的来源：它们分别是 SGD 和 Polyak 的临界 batch 指数。剩下的 \(b_2\)，是 Nesterov 上升的那一段与步数限制相遇的位置。

下面的图把三种方法放在同一组坐标里。调整 \(b\)，可以比较不同 batch 规模下的表现；调整 \(s\) 和 \(\beta\)，则是在改变学习问题本身。

{{EXPLORER}}
  • 小 batch，\(b\leq b_1\)。三种方法的指数都是 \(s/(s+1)\)。动量可能改变常数因子，但不会改善这个指数。
  • 更大的 batch，\(b_1<b<b_3\)。Nesterov 的指数最好，Polyak 其次，SGD 最后。Nesterov 在 \(b_2\) 处达到最高点。
  • 非常大的 batch，\(b\geq b_3\)。Polyak 和 Nesterov 的指数都是 \(2s(1-b)\)，SGD 则是 \(s(1-b)\)。Batch 继续增大时，三种方法的表现都会变差。

\[r_{\mathrm{SGD}}(b)=\min\left\{\frac{s}{s+1},s(1-b)\right\},\]
\[r_{\mathrm{Polyak}}(b)=\min\left\{\frac{s}{s+1},2s(1-b)\right\},\]
\[r_{\mathrm{Nesterov}}(b)=\begin{cases}\frac{s}{s+1},&b<b_1,\\[2pt]\frac{s(1+(\beta-1)b)}{s\beta+1},&b_1\leq b<b_2,\\[2pt]2s(1-b),&b_2\leq b<1.\end{cases}\]

这些是最优调参后的渐近指数，完整结果见论文定理 6.3。

训练曲线里能看到什么？

前面的指数描述数据量很大时的趋势。我们也在同一个回归模型里做了模拟，看看数据有限时，这些预测能不能对上。

同样的数据，换不同的 batch size

固定 \(D=2^{14}\)，每个 batch size 下都重新调学习率和动量，让最终误差尽量低。小 batch 时，SGD、Polyak 和 Nesterov 的误差几乎一样。Batch 逐渐增大，SGD 最先变差，Polyak 则能更久地保持之前的表现。

Nesterov 的误差会先下降，再转头上升。在下降的那段范围里，仅仅改变 batch size 并配合调参，就能让它从同样的数据里学到更多。

增加数据，再换三种 batch 增长规则

接着，采用 \((s,\beta)=(0.3,4)\) 并增加数据预算。让 batch 保持常数量级、按 \(D^{0.4}\) 增长，或按 \(D^{0.8}\) 增长，分别落在前面的三个范围里。每次训练的学习率和动量，按理论给出的缩放规则设置。

几个值得记住的点

Polyak 和 Nesterov 都通过有效学习率 \(\eta/(1-\rho)\) 加快学习。Polyak 保留了 SGD 在学习和噪声之间的最佳平衡，但可以在更大的 batch 下达到它。Nesterov 则在大有效学习率下降低噪声代价，连这个平衡点本身也改善了。

Batch size 决定了我们能不能用上这些收益。小 batch 时，三种方法的数据缩放指数一样；中间这段范围，动量有了发挥空间；batch 非常大时，两种动量方法最终都会受限于更新次数太少。

这里讨论的是 one-pass 核回归，每次训练中的超参数保持固定。这些结果给了我们一个理由，把学习率、batch size 和动量放在一起考虑。进一步允许它们随训练过程变化，是一个自然的下一步。
